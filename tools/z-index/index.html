How stacking works (quick rules)
  • z-index only affects positioned elements (relative/absolute/fixed/sticky), not static.
  • Higher z-index sits on top — but only within the same stacking context.
  • Stacking contexts can be created by: transform, opacity < 1, isolation:isolate, position + z-index, etc.
  • If an element “won’t go above” another, it’s often trapped in a different stacking context.
